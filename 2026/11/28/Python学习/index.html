Python装饰器

装饰器的核心思想是：用一个函数”包装”另一个函数。

def decorate(func):

def wrapper():

    print("前置：额外要做的事")

    func()   # func 就是 hello，func() 执行hello

    print("后置：额外要做的事")

return wrapper

@decorate 装饰器通过 @ 语法糖应用在函数定义前

def hello():

print("我是原来hello的代码")

hello()

@decorate 等价：hello = decorate(hello)

1.把原始的 hello 传给 decorate，func 接住它 → func = hello

2.decorate 返回 wrapper（外壳）

3.现在名字 hello 指向 wrapper

4.执行 hello() → 跑 wrapper

5.wrapper 里面：先打印前置 → func() 跑原来 hello → 打印后置

✅ 一句话记： func 是存进来的原函数，加括号才会跑它。装饰器就是套一层 wrapper 外壳，在原函数前后加代码。

如果原函数有参数，需要在 wrapper 中使用 *args, **kwargs

列表

方法 描述

list.append(x) 把一个元素添加到列表的结尾，相当于 a[len(a):] = [x]。

list.extend(L) 通过添加指定列表的所有元素来扩充列表，相当于 a[len(a):] = L。

list.insert(i, x) 在指定位置插入一个元素。第一个参数是准备插入到其前面的那个元素的索引，

例如 a.insert(0, x) 会插入到整个列表之前，而 a.insert(len(a), x) 相当于 a.append(x) 。

list.remove(x) 删除列表中值为 x 的第一个元素。如果没有这样的元素，就会返回一个错误。

list.pop([i]) 从列表的指定位置移除元素，并将其返回。

如果没有指定索引，a.pop()返回最后一个元素。

元素随即从列表中被移除。（方法中 i 两边的方括号表示这个参数是可选的，

而不是要求你输入一对方括号，你会经常在 Python 库参考手册中遇到这样的标记。）

list.clear() 移除列表中的所有项，等于del a[:]。

list.index(x) 返回列表中第一个值为 x 的元素的索引。如果没有匹配的元素就会返回一个错误。

list.count(x) 返回 x 在列表中出现的次数。

list.sort() 对列表中的元素进行排序。 不返回

list.reverse() 倒排列表中的元素。 不返回

list.copy() 返回列表的浅复制，等于a[:]。

lst.sort()：原地改，返回 None
