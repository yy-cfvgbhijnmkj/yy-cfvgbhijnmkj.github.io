linux命令指令学习

Linux命令指令

whoami 就是看当前是谁 当前登陆的用户名

pwd 看当前的工作路径

查看当前运行的进程 ps aux

终止进程 kill 进程id

/ 是根目录 cd / 查看根目录 我的linux系统进去在子目录home里面

ls 是看我当前子目录里面的文件 子目录

ls -l 查看详细信息

ls -la 查看详细隐藏信息

cd 文件夹/目录 就能跳转到那相应的文件夹目录

ip addr ip a ifconfig 查看网络配置信息

测试虚拟机与主机的连通性 ping 我的ip ping我的名字

创建新目录 mkdir 目录的名字

删除新目录 rmdir 目录的名字 rm -r 目录的名字

切换目录 cd 新目录

创建新的空的文件 touch 文件的名字

删除文件 rm 文件

通过名字在当前目录下查找新建文件 find . name “文件的名字” . 当前文件夹目录

find . name “*.txt” 这个是找以.txt结尾的文件

cp 原来的文件 到的地方 复制文件或者目录到新的地方

mv 旧的文件夹或文件 新的文件夹或文件 移动或重命名文件或目录

cat 文件 连接和显示文件内容

more 文件名字 less 文件名字 逐页看文件的内容

head -n 想看前几行的的行数 文件名 查看文件前几行的内容

tail -n 想看后面几行的行数 文件名 查看文件后几行的内容

grep 你想搜的短语 词 文件名 在文件中搜索指定文本

wget 资源的网络地址 从网络下载文件

curl -0 资源的网络地址 从网络下载文件

chmod 权限 文件名 修改文件权限

所有者 (u)、所属组 (g)、其他用户 (o) 每一位 = 4 (r 读) + 2 (w 写) + 1 (x 执行)

r=4，w=2，x=1

0：无权限

4：r

5：r+x

6：r+w

7：r+w+x

有所有者 (u)、所属组 (g)、其他用户 (o) 所以权限是三位数字

chown：修改文件或目录的所有者

tar [选项] 包名 源文件/目录

包名 = 输出的那个文件名字

源文件 / 目录 = 你要塞进去的东西

选项 -c：create，打包

-x：extract，解压

-f：指定包文件名（f 必须放最后！）

-z：gzip 压缩（后缀 .tar.gz / .tgz）

-j：bzip2 压缩（后缀 .tar.bz2）

-v：verbose，显示过程（看进度）

-t：查看包里内容，不解压

-C：解压到指定目录

-zcvf 压缩打包看进度指定包文件名 打包 + gzip 压缩，后缀 .tar.gz

-zxvf 压缩解压看进度指定包文件名 解压 tar.gz

打包 tar 选项 解压或压缩完的文件名字 原来的文件

打包完的文件名 一般以.tar 结尾

解压 以.tar.gz 结尾

-xvf 解除打包 看进程 指定包文件名 tar -xvf 文件名.tar

df -h 显示磁盘空间的使用情况

du -h 目录名 显示目录的使用情况

top 显示系统资源的实时使用情况和进程信息

ssh 远程连接

scp：安全地将文件从本地复制到远程主机，或从远程主机复制到本地

Find 在什么目录 -name “文件名字”

find . -name “test.txt” 寻找test.txt文件 根据名字找

-type f：f = file，普通文件（txt、sh、tar、png 这些）

-type d：d = directory，目录 / 文件夹

. 当前目录

find . -name “*.txt” 寻找当前目录所有带有.txt 后缀的文件

-i忽略大小写

-n显示匹配行的行号

-r递归搜索目录里所有文件

-v反向匹配，输出不包含关键词的行

-E使用扩展正则（支持 、+）-o只输出匹配到的内容，不输出整行

grep -r “pattern” /path/to/search

. 直接输入一个. 代表在当前目录查找

sed ‘s/old_text/new_text/‘ file_name

sed 流编辑器，用于文本处理和替换

sed ‘s/old_text/new_text/‘ file_name

sudo -i 到root了 exit 退出
