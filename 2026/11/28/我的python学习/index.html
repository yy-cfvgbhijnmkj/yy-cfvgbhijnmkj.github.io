不可变类型 ≈ 可哈希 对象创建之后，内容不能原地修改，哈希值永远不变。

如果你往集合里面输入了一些数据，里面有重复的，那么你输出的结果里面，重复的数字就只输出一次，并且你每次输出的结果可能不一样，输出结果和你输入的集合不一样。并且要求你输入的值必须是不可变类型。他没有固定的位置，所以不可以索引和切片。

match…case

match 后的对象会依次与 case 后的内容进行匹配，如果匹配成功，则执行匹配到的表达式，否则直接跳过，_ 可以匹配一切。

    <action_1>

    <action_2>

case <pattern_3>:

    <action_3>

case _:

    <action_wildcard>

def http_error(status):

    match status:

        case 400:

            return “Bad request”

        case 404:

            return “Not found”

        case 418:

            return “I’m a teapot”

        case _:

            return “Something’s wrong with the internet”

 

print(http_error(400))

print(http_error(404))

print(http_error(418))

print(http_error(500))

你写 http_error(400) → 进入函数，status=400

匹配到 case 400:

执行 return “Bad request”

✅ 作用：把字符串 “Bad request” 送出去，替换掉 http_error(400) 这一块

相当于变成：print(“Bad request”)

print 拿到这个文字，打印到屏幕上

print：函数内部自己输出，不给外面

return xxx：把 xxx 交给外面调用的代码使用

一个 case 也可以设置多个匹配条件，条件使用 | 隔开

✅ 什么时候用 match case

适合：同一个变量，挨个匹配等于哪个固定值（枚举、状态码、选项）

StopIteration

StopIteration 异常用于标识迭代的完成，防止出现无限循环的情况，在 next() 方法中我们可以设置在完成指定循环次数后触发 StopIteration 异常来结束迭代。

class Mynumbers:

def __iter__(self):

    self.num = 1

    return self    # 目的 创造了一个迭代器



def __next__(self):

    if self.num <= 20:

        x = self.num

        self.num += 1

        return x

    else:

        raise StopIteration  #为for做准备 准备输出 一个一个拿元素

myclass = Mynumbers() #实例化 造出了一个实物

myiter = iter(myclass) #调用def next

for i in myiter:

print(i)
