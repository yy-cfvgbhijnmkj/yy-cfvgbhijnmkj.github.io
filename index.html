Python装饰器

装饰器的核心思想是：用一个函数”包装”另一个函数。

def decorate(func):

def wrapper():

    print("前置：额外要做的事")

    func()   # func 就是 hello，func() 执行hello

    print("后置：额外要做的事")

return wrapper

@decorate 装饰器通过 @ 语法糖应用在函数定义前

def hello():

print("我是原来hello的代码")

hello()

@decorate 等价：hello = decorate(hello)

1.把原始的 hello 传给 decorate，func 接住它 → func = hello

2.decorate 返回 wrapper（外壳）

3.现在名字 hello 指向 wrapper

4.执行 hello() → 跑 wrapper

5.wrapper 里面：先打印前置 → func() 跑原来 hello → 打印后置

✅ 一句话记： func 是存进来的原函数，加括号才会跑它。装饰器就是套一层 wrapper 外壳，在原函数前后加代码。

如果原函数有参数，需要在 wrapper 中使用 *args, **kwargs

不可变类型 ≈ 可哈希 对象创建之后，内容不能原地修改，哈希值永远不变。

如果你往集合里面输入了一些数据，里面有重复的，那么你输出的结果里面，重复的数字就只输出一次，并且你每次输出的结果可能不一样，输出结果和你输入的集合不一样。并且要求你输入的值必须是不可变类型。他没有固定的位置，所以不可以索引和切片。

StopIteration

StopIteration 异常用于标识迭代的完成，防止出现无限循环的情况，在 next() 方法中我们可以设置在完成指定循环次数后触发 StopIteration 异常来结束迭代。

class Mynumbers:

def __iter__(self):

    self.num = 1

    return self    # 目的 创造了一个迭代器



def __next__(self):

    if self.num <= 20:

        x = self.num

        self.num += 1

        return x

    else:

        raise StopIteration  #为for做准备 准备输出 一个一个拿元素

十进制整数转二进制：除 2 取余，逆序排列

核心口诀：除以 2，记录余数，商继续除 2，直到商 = 0；最后余数从下往上写就是二进制

举例子：把 102 转二进制

1.(102 ÷ 2 = 51) 余 (\boldsymbol{0})

2.(51 ÷ 2 = 25) 余 (\boldsymbol{1})

3.(25 ÷ 2 = 12) 余 (\boldsymbol{1})

4.(12 ÷ 2 = 6) 余 (\boldsymbol{0})

5.(6 ÷ 2 = 3) 余 (\boldsymbol{0})

6.(3 ÷ 2 = 1) 余 (\boldsymbol{1})

7.(1 ÷ 2 = 0) 余 (\boldsymbol{1})

停止条件：商变成 0 就不除了 余数从上到下：0 1 1 0 0 1 1 逆过来（从最后一个余数读到第一个）：1100110 也就是 (102_{10}=1100110_2)

可变

一一对应 key不可变 不可以重复

可以是任何类型

tinydict = {‘Name’: ‘Runoob’, ‘Age’: 7, ‘Class’: ‘First’}

键要放到方括号里面

修改字典

向字典添加新内容的方法是增加新的键/值对，修改或删除已有键/值对如下实例:

tinydict = {‘Name’: ‘Runoob’, ‘Age’: 7, ‘Class’: ‘First’}

tinydict[‘Age’] = 8 # 更新 Age

tinydict[‘School’] = “菜鸟教程” # 添加信息

print (“tinydict[‘Age’]: “, tinydict[‘Age’])

print (“tinydict[‘School’]: “, tinydict[‘School’])

就是什么都是一对一对的
